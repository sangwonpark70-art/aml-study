1. FATF — 설립·관할·평가

연도와 순서가 곧 점수인 구간. 숫자를 사건과 묶어 외운다.

① 설립·명칭·관할 확대 ★★★

FATF = Financial Action Task Force, 1989년 G7 정상회의에서 마약자금 세탁 방지 목적으로 설립. 한국 가입 1996년.

연도관할 확대
1989마약자금 (설립 목적)
1996중대범죄 전반으로 확대
2001테러자금조달 (9·11 직후 8개 특별권고)
2012대량살상무기 확산금융(WMD) — 40권고 통합 개정

국내: 특금법 제정·KoFIU 설립 2001년 / FATF 4차 라운드 상호평가 2019년 수검.

함정: "설립 목적 = 테러자금 방지" → X (마약자금). 테러자금은 2001년 이후 편입. 순서를 뒤섞은 선지가 단골이다.

② 상호평가(ME) 2축과 등급 ★★★

축대상등급 4단계
기술적 이행 (TC)40개 권고의 법령·제도 정비 수준C → LC → PC → NC
(이행·대부분·부분·미이행)
효과성 (EO)11개 즉시성과(IO)로 실제 작동 여부High → Substantial → Moderate → Low

주요 IO: IO.5 법인·법률관계 남용 방지 / IO.9 금융기관 의무이행. ICRG = 미흡국 집중 모니터링 절차.

함정 ①: 두 등급 체계를 바꿔 출제한다 — C/LC/PC/NC는 기술적 이행, High/Substantial은 효과성.
함정 ②: "PC = 법령이 전혀 없다" → X. 전무는 NC. PC는 일부 갖춰진 상태.
함정 ③: 상호평가 등급만으로 대응조치 대상국이 자동 지정되지 않는다 — 별도 절차.

③ 고위험국가 2단계 성명서 ★★

① 대응조치 요구 대상국(통칭 블랙리스트) — 대응조치(counter-measures) 적용 요구. 대표: 이란·북한.
② 강화된 관찰대상국(Jurisdictions under Increased Monitoring, 통칭 그레이리스트) — 강화된 고객확인 등 위험 반영 요구.

함정: "블랙리스트 하나만 존재" / "회원국·비회원국으로 구분" → X. 2단계 체계임을 묻는다.

2. 국제협약과 국제기구

협약은 연도+대상범죄 세트, 기구는 성격 구분이 핵심.

④ 3대 협약 — 연도·대상 ★★★

협약연도대상
비엔나협약1988마약 — 자금세탁 최초 범죄화
팔레모협약2000초국가조직범죄 — 전제범죄 중대범죄 전반으로 확대
메리다협약(UNCAC)2003부패방지

자금세탁 정의의 국제법적 근거 = 비엔나 + 팔레모 2개. 테러자금조달 제도 확산의 직접 계기 = 9·11 테러(2001) 및 UN 안보리 결의.

함정: 정의 근거를 물으면 비엔나·팔레모다. 메리다(부패)·바젤(은행감독)을 섞은 선지 주의.

⑤ 에그몽 그룹 ★★★

1995년 벨기에 브뤼셀 에그몽-아렌버그 궁에서 출범. 각국 FIU 간 정보교환·협력 국제협의체.

보안 전용망 = ESW(Egmont Secure Web). KoFIU 2002년 가입.

함정: 성격이 다른 4개 기구를 섞어 낸다 — FATF(정부간, 권고 제정) / 에그몽(FIU 협의체) / BCBS(BIS 산하 은행감독) / 볼프스베르그(민간 은행 협의체). ESW를 SWIFT·goAML로 바꾼 선지도 나온다.

⑥ 볼프스베르그·BCBS·EU AMLD ★★

기구·규범성격
볼프스베르그 그룹글로벌 민간 은행 자율 협의체. 법적 구속력 없음. 프라이빗뱅킹 AML 원칙·환거래은행 실사질의서(CBDDQ)
BCBSBIS 산하 은행감독 기준 제정. KYC 지침. 제재·수사 권한 없음
APGFATF 아시아·태평양 지역기구(FSRB)
UNODC유엔 마약·범죄 대응 기구. goAML 개발

EU AMLD: 1차(1991) → 3차(2005) RBA 도입 → 4차(2015) → 5차(2018) 가상자산 편입.

함정: RBA 최초 도입 차수를 4차·5차로 바꿔 낸다 → 3차(2005).

3. 40개 권고 — 번호와 주제

최다 출제 구간. 번호 매칭·개수형으로 반복된다.

⑦ 필수 암기 번호 ★★★

가장 잘 틀리는 3쌍 — 20(STR) ↔ 21(누설금지) / 24(법인 BO) ↔ 25(신탁 BO) / 16(전신송금) ↔ 17(제3자 의존). 개수형에서 이 쌍을 바꿔 넣는다.

⑧ 개별 권고 심화 — 12·6·7·8·32·40 ★★★

R.12 PEP: 외국 PEP는 위험 무관 항상 EDD / 국내·국제기구 PEP는 위험도에 따라. 가족·측근 포함, 퇴임 후에도 일정 기간 유지. PEP는 위험 지표이지 범죄자 확정이 아니며 거래 금지 요구도 아니다.

R.6 / R.7 TFS: 6=테러·테러자금(UN 1267·1373) / 7=WMD 확산금융(북한·이란). 핵심어 without delay — 당국 통보를 기다리지 않고 명단 확인 즉시 동결. 동결 후 STR 제출 + 감독당국 보고. 오탐 해제는 당국 승인 필요(금융기관 임의 불가).

R.8 NPO / R.32 현금·무기명 지급수단 국경 휴대 / R.40 기타 형태의 국제협력.

TFS 오답 서술: "통보를 받은 후 동결" / "거래 거절로 충분" / "금융기관이 직접 해제" → 전부 X.

⑨ R.21 면책·누설금지 / R.1 RBA ★★★

R.21: ① 보고 사실을 고객·제3자에게 누설 금지 ② 선의 보고는 계약상·법률상 비밀유지 위반 아님. 사후에 범죄와 무관으로 밝혀져도 면책 유지(소급 취소 없음) — 결과책임을 지우면 보고가 위축되기 때문.

R.1 RBA: 국가는 위험을 확인·평가하고 문서화·최신화. 고위험 → 강화조치, 저위험 → 간소화 허용. 다만 간소화는 절차 일부 완화일 뿐 신원확인 자체 면제가 아니다. NRA 결과는 금융회사 자체 위험평가에 반영되어야 한다.

함정: "위험이 낮으면 신원확인 생략 가능" → X. "모든 고객에 동일 CDD 적용" → RBA 위반이다.

⑪ 자금세탁 3단계·특성 ★★

예치(Placement) → 은폐·반복(Layering) → 통합(Integration). 현금 입금은 예치 단계.

특성: 국제범죄성 · 조직범죄성 · 화이트칼라형 · 반복성. 개인범죄성은 특성이 아니다.

함정: 3단계 순서를 뒤집거나(은폐→예치), 특성에 "개인범죄성"을 끼워 넣는다.
