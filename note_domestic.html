1. 자금세탁방지 법체계 — 3법 구조

시험의 뼈대. 법률 간 역할 구분이 매년 나온다.

① 3법의 역할 분담 ★★★

법률역할키워드
특정금융정보법보고·분석·정보제공 (행정)STR·CTR·CDD·FIU
범죄수익은닉규제법자금세탁 처벌·몰수 (형사)제3조 은닉·가장, 종사자 신고의무(제5조①)
마약류불법거래방지법마약 관련 불법수익 (형사)제7조 불법수익 은닉

자금세탁 개념을 규정하는 법: 범죄수익은닉규제법 + 마약류불법거래방지법 + 특정금융정보법(제2조 제5호 — 조세포탈 목적 포함).

함정: 종사자의 수사기관 신고 의무 = 범죄수익은닉규제법 제5조①이다. 특금법·형사소송법 아님. 이 신고는 특금법상 STR 사유(제4조①3호)와 연결된다.

② 규제체계 3축·차명거래·벌칙 ★★

규제체계 3축: 특금법(보고) — 범죄수익은닉규제법(처벌) — 테러자금금지법(공중협박자금).

차명거래 제재 근거 = 금융실명법(불법재산 은닉 등 목적의 차명거래 금지). 전제범죄는 범죄수익은닉규제법 별표의 중대범죄 체계로 규정.

특금법 과태료 상한: 제20조 — 1억원 이하(미보고 등) / 3천만원 이하 구간 구분. 벌칙(형벌)과 과태료(행정) 구분 주의 — STR 누설은 형벌(징역·벌금) 대상.

2. 금융정보분석원 (KoFIU)

기관 성격 + 도입 연혁. 숫자(연도) 암기 구간.

③ FIU 성격과 연혁 ★★★

2001년 설립, 특금법 제3조 근거. 행정형 FIU — 수사·기소 권한 없음. 보고 수집·분석 후 법집행기관(검찰·경찰·국세청·관세청 등)에 제공하는 구조.

제도 도입 순서: STR(2001) → CTR(2006) → CDD(2006)·강화(2008). 에그몽 그룹 가입 2002년.

함정: "FIU는 수사기관이다" / "STR 보고는 고발이다" — 전부 틀린 서술. 보고≠고발이 반복 출제.

3. 내부통제 — 구성원별 역할 · 3선방어 · 감사

국내제도 최다 출제 구간. 2026.1.22 개정 반영 필수.

④ 구성원별 역할과 책임 ★★★

주체역할
이사회업무지침 제정·개정·폐지 / 경영진 감독 / 감사결과 보고받음
대표이사내부통제 총괄 구축·운영 / 보고책임자 임명 / 지침안 이사회 상정
보고책임자STR·CTR 보고 / 고객확인 총괄 / 직원알기제도 수립·운영 / 교육 연 1회↑
준법감시인등임직원의 업무지침 준수 여부 감독 (제5조의2 신설)
개정(FIU고시 제2025-2호, 시행 2026.1.22): 종전 "경영진" 조문이 "대표이사"(제5조)로 개편, 준법감시인등(제5조의2) 신설. 구판 기준 암기 = 오답.
함정: "보고책임자 임명 = 이사회" → X (대표이사). "지침 제·개정 = 대표이사" → X (이사회).

⑤ 3선 방어체계 ★★★

1선 영업·현업(고객확인 이행, 의심거래 최초 인지) → 2선 준법감시·리스크관리(정책 수립·모니터링) → 3선 내부감사(1·2선의 적정성 독립 검증).

함정: "감사팀장이 보고책임자 겸임이 바람직" → X. 자기가 한 일을 자기가 감사하게 되어 독립성 붕괴(FIU 유권해석 사례 92).

⑥ 직원알기·독립적 감사·교육 — 조문·주기 ★★★

제도조문핵심
직원알기제도제10조(정의)채용 시+지속. 보고책임자 소관
독립적 감사체계제12조(정의)·제14조(주기)연 1회 이상, 감사/감사위원회 실시
교육·연수—연 1회 이상, 보고책임자 실시

감사 실시자: 감사·감사위원회 원칙, 예외적으로 타 내부부서·외부전문가 가능. 단 AML 담당부서는 불가(피감 대상). 결과 보고 → 이사회.

함정: "감사 연 1회 = 보고책임자 실시" → 주체 뒤바꿔 출제. 감사=감사(위), 교육=보고책임자. 같은 '연 1회'라 혼동 유도.

4. 의심거래보고 (STR)

면책·누설금지·증거능력·정보공유 — 4종 세트로 묶어 암기.

⑦ 보고의 성격·면책·증거능력 ★★★

보고 = 정보 제공(≠고발). 기준금액 없음(2013 폐지) — 의심되는 합당한 근거가 있으면 지체 없이.

선의 보고 면책: 결과적으로 범죄와 무관해도 비밀유지 의무 위반 아님. 사후 사실이 아니어도 면책 유지(소급 취소 없음).

증거능력: STR 정보는 재판에서 증거로 사용 불가(특금법 제12조③) — 수사 단서로만.

내부보고체제: 작성자와 검토자·보고책임자 분리 원칙(소규모 금융회사는 예외 허용).

⑧ 정보누설 금지와 예외 2가지 ★★★

보고 사실을 거래 상대방 포함 타인에게 누설 금지(tipping-off). 예외는 딱 둘:

① 동일 금융회사 내부 정보공유 · ② 해당국 법령에 근거 있는 외국 FIU와의 교환.

함정: "언론에 공익 목적 제공 가능" / "계열사 간 공유 가능" → 전부 X. 예외 2가지 외 전부 누설.

5. CTR · 기록보존 — 숫자 세트

숫자만 정확하면 다 맞는 구간. 혼동 쌍으로 외울 것.

⑨ 핵심 숫자 일람 ★★★

항목숫자혼동 포인트
CTR 기준금액1천만원 (2019.7~)법률은 대통령령 위임 방식
CTR 합산1거래일·동일인·동일 금융회사↔ 연결거래 7일과 반드시 구분
연결거래(CDD) 합산7일
기록 보존거래관계 종료 시부터 5년↑기산점이 거래일 아님

CTR 중계기관: 은행연합회·금융결제원 등 지정 — 보고는 FIU로, 중계기관은 전달 통로.

6. 고객확인 · 실제소유자 (국내제도 파트)

실무편 CDD와 겹치지만, 여기선 특금법 조문 각도로 나온다.

⑩ 실제소유자 3단계·확인 거부 시 조치 ★★★

법인 실제소유자: ① 25%↑ 지분 개인 → ② 최다 지분자 등 → ③ 대표자 순 단계적 확인. 복수 가능.

고객이 확인에 불응: 신규 거래 거절·기존 거래 종료 가능 + 이 경우 STR 검토 의무.

확인 면제 가능 대상: 국가·지자체·공공단체 등(사업자번호 중간 83=국가기관 계열 → 면제 가능성, 81=영리법인 → 면제 아님).

제3자를 통한 고객확인(위탁): 최종 책임은 위탁한 금융회사에 남는다.

7. 적용대상 — "금융회사등"의 범위

포함/불포함 판별형. 경계 사례를 외운다.

⑪ 포함·불포함 경계 ★★

포함: 은행·보험·금융투자·상호금융·카지노·가상자산사업자·전자금융업자·대부업자(자산 500억↑ 등 요건 충족 시)·부동산 신탁사(신탁업 겸영 범위) 등.

함정: 대부업자는 "전부 포함"이 아니라 요건 충족분만. 특금법이 직접 규정하지 않는 사항(예: 자금세탁 형사처벌)을 "특금법 규정"으로 낸 오답 선지 주의.

8. 가상자산사업자 (VASP)

최신 개정(2026.8.20 시행) 포함 — 이번 회차 출제 유력 구간.

⑫ 신고 숫자 세트 ★★★

항목숫자
신고 유효기간법 상한 5년 / 시행령 3년
갱신신고만료 45일 전까지
말소 후 재신고 제한5년
결격(벌금형↑) 경과기간집행 종료·면제일부터 5년
함정: "유효기간 5년"만 외우면 틀린다 — 법 상한 5년, 실제는 시행령 3년. 말소 후 "3년"도 오답 단골.

⑬ 2026.8.20 시행 개정 + 사업자 의무 ★★★

개정 4대 포인트: ① 신고사항에 대주주 관련 사항 추가 ② 불수리 사유 인적 범위에 대주주 포함(최대주주의 특수관계인·법인 배후의 사실상 영향력 행사자까지) ③ 관련 법률 범위 확대(조세범처벌법·공정거래법·가상자산이용자보호법 등) ④ 퇴임 임원 조치내용 통보 신설. CTR 기준금액 인하는 개정 내용 아님.

사업자 의무: 고객별 거래내역 분리 / 예치금 구분 관리 / 미신고 사업자와 영업 목적 거래 금지 / 자사·임직원 거래는 제한 기준 마련 대상(허용이 아님).
